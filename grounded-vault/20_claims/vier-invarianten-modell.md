# Jede Gestalt zeigt vier Invarianten, Einheiten, Fluss, Regeln und Lücken

## Statement

Das generalisierte UI-Modell trennt eine invariante Struktur von der austauschbaren Metapher darüber. Die Struktur besteht aus antippbaren Wissenseinheiten, einer sichtbaren Richtung von Zeit oder Prozess, dem Steuernden als dem einen durchwirkenden Element und den immer sichtbaren Lücken. Ein Geisterdokument wird nie stillschweigend weggelassen.
