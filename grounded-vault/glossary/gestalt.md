# Gestalt

Eine konkrete visuelle Ausprägung des generalisierten UI für ein Projekt, etwa Nachtgarten, Organismus, Werkstrecke, Helio oder Planet. Jede Gestalt wird gegen die Anforderungsliste der Spezifikation abgenommen. [[00_representation/documents/most-specification#^p01]]
